Capstone exercise

You join a retailer with one ECC 6.0 EHP8 system, 4,000 custom objects, retail-price inventory valuation in two countries and cost valuation in one, and a board-fixed go-live before December 2027. Write a one-page approach that covers: the transition path (Module 7), how you will settle valuation before any build starts (Module 5, the Lidl lesson), how many mock conversions you plan and what each must reconcile (Module 8), a rule for every new custom object (Module 9), and one agent you would switch on in the first year, with its autonomy threshold and ROI baseline (Modules 12–14). If you can defend each choice with a case from this guide, you are working at expert level.
